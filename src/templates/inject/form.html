Inject SVG Translations

Extract translations from a source file and inject them into a target file. The result shows a before/after diff of the target's translations.

File to extract translations from (you can omit the "File:" prefix)
File to inject translations into (you can omit the "File:" prefix)
What does this do?
  1. Downloads the source SVG and extracts its translations
  2. Downloads the target SVG and extracts its current translations
  3. Injects the source translations into the target SVG
  4. Re-extracts translations from the modified target
  5. Shows a diff of what was added, changed, or removed

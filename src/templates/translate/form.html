How Interactive Translation Works
  1. We download the SVG file from Wikimedia Commons.
  2. We parse and extract all text elements (like headings, labels, legends) and show them to you.
  3. You can modify existing translations or add new ones directly in the editor.
  4. We inject your translations and upload the updated SVG file directly to Wikimedia Commons!

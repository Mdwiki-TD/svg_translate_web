## 2025-02-13 - [OwidCharts JSON Export Optimization via Left Outer Join]
**Learning:** The OWID charts download-json export endpoint previously loaded all charts, queried an additional database view (`OwidChartTemplateView`), and constructed a mapping hash-map in-memory to resolve chart-to-template associations. By utilizing the existing `list_charts_with_templates()` service method, we can execute a single unified SQL LEFT OUTER JOIN query, eliminating extra database roundtrips, reducing SQLAlchemy model instantiation, and lowering constant execution factors in O(N) operations.
**Action:** Always inspect the database services layer for pre-existing unified queries (e.g., those utilizing LEFT OUTER JOINs) before implementing separate model/view queries and in-memory joins in handlers or route definitions.
